Filter Chip Design Approaches

Each approach shown at two sizes. The chip for "주문서 + 보석" is the active/selected state.

A — Ghost / Outline Only

Inactive: transparent bg, subtle border, normal weight. Active: filled accent bg, white text, no border. Maximum contrast between states.

Default size (padding 6px 14px, 0.82rem)

Compact (padding 3px 10px, 0.76rem)

B — Muted Pill Tags

Inactive: very subtle gray fill, no visible border, pill shape. Active: accent bg, white text. Most compact and understated.

Default size (padding 4px 12px, 0.80rem)

Compact (padding 2px 10px, 0.74rem)

C — Segmented Control

All chips joined into a single bar. Only the selected segment is filled. Unmistakable selection, very compact.

Default size (padding 5px 14px, 0.80rem)

Compact (padding 3px 10px, 0.74rem)
