Approaches for the Chaos Scroll Card Layout

Common to all: icon + "혼돈의 주문서" on the left (no subtitle, vertically centered), per-stat dual-range sliders on the right in Filter mode. Difference is in stat row arrangement.

A

Vertical Stack (recommended)

Each stat gets one row with label + min~max readout + dual-range slider. Rows stack vertically inside the right area. Matches the stimulant bounds editor pattern already in the codebase — no new layout invented.

Left: 혼돈의 주문서

Right:
공격력  0~5  ━━━━━━━
STR    -2~3  ━━━━━━━
DEX    0~4  ━━━━━━━
LUK    -1~2  ━━━━━━━
B

Two-Column Grid

Stat rows laid out in a 2-column grid to save vertical height. Each cell contains label + min~max + compact slider. Works better when there are 4+ target stats.

Left: 혼돈의 주문서

Right (2-col):
공격력 0~5 ━━━   STR -2~3 ━━━
DEX 0~4 ━━━    LUK -1~2 ━━━
C

Inline Slider Rows (compact)

Label on the left, dual-range track with min/max readout inline. Saves horizontal space, good when name is short. Each row is as compact as possible.

Left: 혼돈의 주문서

Right:
공격력 ━0━━━━5━   STR ━-2━━━3━
DEX ━0━━━━4━   LUK ━-1━━━2━
